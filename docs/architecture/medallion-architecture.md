# Medallion Architecture

## Bronze

Store raw source data exactly as received.

Examples:

- ERP exports
- CRM extracts
- HR files

---

## Silver

Clean and standardize data.

Examples:

- Remove duplicates
- Standardize formats
- Data quality checks

---

## Gold

Business-ready data structures.

Examples:

- FactSales
- DimCustomer
- DimProduct
- DimEmployee
